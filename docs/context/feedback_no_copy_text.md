Never copy exact phrases, headlines, or body text from reference websites. Take inspiration from the structure, design patterns, and positioning strategy, but always write original copy.

**Why:** User asked to be inspired by HappyRobot.ai's design. The headline "Intelligence that runs your operations" was copied word-for-word. That's plagiarism, not inspiration.

**How to apply:** When the user shares a reference site, analyze the design patterns, layout structure, color system, typography, and positioning strategy. Then write completely original text that captures the same tone and energy but with Tumai's own voice and messaging.
